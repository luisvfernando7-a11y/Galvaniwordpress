# Instruções para Codex
Leia CONTEXTO.md antes de trabalhar.
Este repositório guarda tema, plugins próprios e documentação.
Não versione o núcleo WordPress, uploads, banco ou credenciais.
Nunca leia ou exponha senhas para compor documentação.
Mantenha a indicação de projeto fictício.
Use APIs WordPress, escape de saída, sanitização, nonces e permissões.
Não crie autenticação própria; use WordPress/WooCommerce.
Priorize responsividade, teclado, foco visível e reduced-motion.
Valide PHP e JavaScript e relate os testes realizados.
Não altere Apache, MariaDB ou outros projetos sem necessidade autorizada.
Atualize CONTEXTO.md com progresso, decisões e pendências.
